# crazy-project-wont-work
โปรเจกต์บ้าๆ ที่ยังไม่เวิร์ค (แต่จะทำให้เวิร์คสักวัน)

## เว็บไซต์ตัวอย่าง: คลินิกจิตเวชและการนอนหลับ "นิทราใจ"

เว็บไซต์ภาษาไทยหลายหน้า สำหรับจิตแพทย์ที่ให้คำปรึกษาเรื่องการนอนหลับ เขียนด้วย HTML และ CSS ล้วน ไม่มี JavaScript รองรับมือถือและโหมดมืด

> **ข้อมูลทั้งหมดเป็นข้อมูลสมมติ** ทั้งชื่อคลินิก ชื่อแพทย์ ประวัติ เบอร์โทร และที่อยู่ เพื่อใช้สาธิตเท่านั้น ก่อนนำไปใช้จริงต้องแทนที่ด้วยข้อมูลที่ถูกต้อง

### โครงสร้างโฟลเดอร์

```
site/             เว็บไซต์ที่เผยแพร่จริง (ไฟล์ .html ถูกสร้างจาก src/)
  assets/         สไตล์ (styles.css) โลโก้ และฟอนต์ไทย (Noto, สัญญาอนุญาต SIL OFL)
src/
  build.py        ตัวสร้างหน้า ใส่เมนู ส่วนท้าย และข้อมูลติดต่อให้ทุกหน้า
  pages/          เนื้อหาของแต่ละหน้า
.github/workflows/main.yml   นำโฟลเดอร์ site/ ขึ้น GitHub Pages อัตโนมัติเมื่อ merge เข้า main
```

### ดูตัวอย่างในเครื่อง

เปิดไฟล์ `site/index.html` ด้วยเบราว์เซอร์ได้เลย

### แก้ไขเนื้อหา

1. แก้ไขไฟล์ใน `src/pages/` (ข้อมูลติดต่อ ชื่อคลินิก และชื่อแพทย์อยู่ที่ส่วน `CONFIG` ใน `src/build.py`)
2. รัน `python3 src/build.py` เพื่อสร้างไฟล์ใน `site/` ใหม่ ตัวสร้างจะตรวจลิงก์เสียให้ด้วย
3. Commit ทั้ง `src/` และ `site/`

### เผยแพร่

ตั้งค่า GitHub Pages ที่ Settings → Pages → Source เป็น **GitHub Actions** แล้ว merge เข้า `main` เว็บจะอัปเดตเองที่ `https://<ชื่อบัญชี>.github.io/crazy-project-wont-work/`
